# About the site

The site is a static site built with [Astro](https://astro.build), using React components for the interactive parts, [Tailwind CSS](https://tailwindcss.com) for styling and the [CSC design system](https://design-system.csc.fi) (`@cscfi/csc-ui`) for UI components. Site search is provided by [Pagefind](https://pagefind.app).

The previous version of the site, built with Jekyll and webpack, is available at https://github.com/FiQCI/dev-old.


# Running locally

All of the commands shown are to be executed in the repository root.

## Using Docker

A [`Dockerfile`](./Dockerfile) and [`docker-compose.yml`](./docker-compose.yml) are provided to build and view the website locally using a containerised environment, without installing Node.js. To build the docker container use

```sh
docker compose build
```

And then run the container with:

```sh
docker compose up
```

The container builds the site once (so that search works) and then starts the dev server with live reload. The site is viewable at [`http://localhost:4321/`](http://localhost:4321/). After dependencies in `package.json` change, rebuild and start with `docker compose up --build --renew-anon-volumes` so the container gets a fresh `node_modules`.

## Requirements

- Node.js 22.12 or newer
- npm

Check your version with

```console
$ node --version
v22.22.3
```

## Install the Node packages

```bash
npm install
```

## Serve with live reload

```bash
npm run dev
```

The site is served at [`http://localhost:4321`](http://localhost:4321) and reloads automatically when the source changes.

## Build and preview

```bash
npm run build
```

builds the site into `dist/`. To view the built site locally, run

```bash
npm run preview
```

## Search

The search index is generated by Pagefind at the end of `npm run build`. The dev server serves the index from the latest build in `dist/`, so run `npm run build` at least once before using search with `npm run dev`, and again to pick up new or changed content in search results.

## Environment variables

| Variable | Purpose |
| :-- | :-- |
| `GITHUB_REPOSITORY` | Set automatically by GitHub Actions. `FiQCI/fiqci.github.io` builds the production site (`https://fiqci.fi`, sitemap, indexable). Anything else, including local builds, builds the dev site (`https://dev.fiqci.fi`, `noindex`, no sitemap). |
| `PUBLIC_MATOMO_URL` | Matomo host for analytics. Analytics are disabled when unset. |
| `PUBLIC_MATOMO_TAG_MANAGER_CONTAINER` | Matomo Tag Manager container id. |

## GitHub Pages

Pushed changes can also be previewed at either https://dev.fiqci.fi/ for the dev site or https://fiqci.fi/ for the main site.


# Project structure

```text
public/assets/          images, PDFs and other static files, served at /assets/...
src/content/
  publications/         blog posts, instructions, news and resource calls (Markdown)
  events/               events (Markdown)
src/data/
  constants.yml         site texts, navigation, alerts and per-page content
  authors.yml           publication authors
src/pages/              routes; each file becomes a URL
src/layouts/            page layouts (base, page, post)
src/components/         React and Astro components
src/lib/                build-time helpers (site data, environment, Markdown plugins)
src/styles/global.css   Tailwind entry point and csc-ui overrides
```

Page URLs are kept identical to the previous site: publications are served at `/publications/<file name>.html` and events at `/events/<file name>.html`, which redirects to the event's external link.
